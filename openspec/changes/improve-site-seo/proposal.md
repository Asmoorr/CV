## Why

Сайт уже отдаёт индексируемые локализованные страницы с базовыми title и description, но не передаёт поисковым системам полный набор сигналов о канонических URL, языковых альтернативах, структуре профиля и карте сайта. Целенаправленная SEO-база повысит корректность обхода и понимания контента, улучшит представление сниппетов и даст измеримый процесс дальнейшего роста без обещаний конкретной позиции в выдаче.

## What Changes

- Ввести единый, обязательный публичный origin сайта и использовать его для абсолютных canonical, hreflang, sitemap, Open Graph и structured data URL.
- Расширить метаданные `/ru` и `/en`: уникальные локализованные title и description, self-canonical, взаимные языковые альтернативы с `x-default`, robots directives, Open Graph и Twitter Card.
- Добавить XML sitemap только с каноническими индексируемыми URL и языковыми альтернативами; связать sitemap из `robots.txt`.
- Добавить валидируемый JSON-LD, описывающий страницу-профиль и человека только фактами, видимыми на странице, с устойчивыми `@id` и согласованными локализованными URL.
- Добавить брендированное изображение для предпросмотра ссылок и полный набор релевантных иконок/метаданных без зависимости от исполняемого клиентского JavaScript.
- Улучшить поисковую релевантность видимого RU/EN-контента: явно и естественно сформулировать специализацию, компетенции, опыт и результаты, сохранив достоверность и отказавшись от keyword stuffing или скрытого SEO-текста.
- Зафиксировать технические проверки для rendered HTML, sitemap, robots, canonical/hreflang, structured data, HTTP-поведения и production build.
- Ввести post-release baseline и мониторинг через Google Search Console, Bing Webmaster Tools и полевые Core Web Vitals, чтобы оценивать индексирование, запросы, CTR и реальные показатели LCP/INP/CLS.

## Capabilities

### New Capabilities

- `search-discoverability`: Индексируемость, локализованные поисковые сигналы, структурированные данные, social previews, техническая производительность и измеримый SEO-контроль качества для страниц резюме.

### Modified Capabilities

Нет: в основном каталоге OpenSpec пока нет действующих capability-спецификаций.

## Impact

- Затрагиваются маршруты и Metadata API в `src/app`, локализованная модель контента, статические/генерируемые metadata assets, конфигурация публичного origin, тесты и эксплуатационная документация.
- Корневой `/` сохраняет перенаправление на `/ru`; индексируемыми целевыми страницами остаются `/ru` и `/en`.
- Возможна небольшая корректировка публичного текста обеих локалей, но факты резюме, визуальная композиция и существующие контактные действия остаются совместимыми.
- Новая runtime-зависимость не требуется; типизация JSON-LD внешней библиотекой допускается только при отдельном обосновании.
- Фактические домен, ownership verification и доступ к кабинетам поисковых систем должны быть переданы окружением/операционной настройкой и не должны хранить секреты в репозитории.
