# Переключение языка

`/ru` и `/en` сохраняют серверный HTML, метаданные и исходный язык своего маршрута. Кнопки RU/EN меняют локальное состояние React без навигации, сетевых запросов, изменения адреса или сброса прокрутки. Перезагрузка возвращает язык маршрута. Выбор не сохраняется между посещениями.

`LocaleTransitionProvider` хранит текущий язык, `ResumeContent` передаёт словарь всем разделам. При переключении обновляется `html.lang`. Канонический адрес и SEO-метаданные остаются связанными с исходным URL.

Видимые текстовые узлы получают декоративные копии: в течение 2,2 секунды случайные буквы выбранного алфавита постепенно собираются в итоговые слова. Размеры слов остаются стабильными во время перебора символов. Изменившиеся размеры блоков, ссылок и заголовков интерполируются Web Animations API. Исходные текстовые узлы сохраняются для средств чтения и возвращаются после анимации.

Повторное переключение во время анимации игнорируется. Мобильное меню закрывается и освобождает прокрутку. При reduced motion текст меняется сразу. Изменение размера окна, уход вкладки в фон или включение reduced motion завершают эффект и очищают временную разметку. Таймер страхует завершение; при размонтировании ресурсы освобождаются.

Браузерные тесты проверяют оба направления, неизменность URL и дерева страницы, отсутствие сетевых запросов, язык после перезагрузки, анимацию видимых разделов, прокрутку, мобильное меню и reduced motion.
