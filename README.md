# Артём Трикула — CV

Двуязычный сайт-резюме на Next.js. Исходный `cv.html` сохранён как референс предыдущей версии.

## Запуск

Требования: Node.js 24+, npm и, для контейнерного запуска, Docker.

```bash
npm ci --legacy-peer-deps
npm run dev
```

Откройте `http://localhost:3000/ru` или `http://localhost:3000/en`.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

`npm test` запускает быстрые проверки структуры контента без браузера.

## Визуальные тесты

Визуальные тесты сравнивают полные страницы `/ru` и `/en` с эталонными PNG на трёх разрешениях: desktop 1440×1000, tablet 768×1024 и mobile 320×800. Для воспроизводимого результата используется Chromium, соответствующий зафиксированной версии Playwright.

После установки зависимостей один раз установите браузер:

```bash
npx playwright install chromium
```

Обычная проверка сама собирает production standalone-версию, запускает её на тестовом порту и не изменяет эталоны:

```bash
npm run test:visual
```

Если внешний вид отличается, команда завершится ошибкой. Expected, actual и diff-изображения вместе с HTML-отчётом сохраняются в `artifacts/playwright`. Откройте отчёт так:

```bash
npm run test:visual:report
```

Если изменение дизайна намеренное, сначала просмотрите все различия и только затем обновите эталоны:

```bash
npm run test:visual:update
npm run test:visual
```

Проверьте новые PNG в `tests/visual/resume.visual.ts-snapshots` перед коммитом. Не обновляйте эталоны только ради зелёного теста. После обновления Playwright или смены поддерживаемой ОС снимки могут потребовать отдельного осознанного пересоздания из-за различий браузерного рендеринга.

## Docker

```bash
docker build -t artem-trikula-cv .
docker run --rm -p 3000:3000 artem-trikula-cv
```

После запуска проверьте `http://localhost:3000/ru` и `http://localhost:3000/en`.

## Где редактировать тексты

Русская версия находится в `src/content/ru`, английская — в `src/content/en`. Каждая секция вынесена в отдельный файл: `navigation`, `hero`, `about`, `timeline`, `projects`, `skills`, `contact` и `footer`. Общая схема данных — `src/content/schema.ts`.

Не добавляйте биографические строки непосредственно в JSX: компоненты должны оставаться независимыми от конкретного текста.

## Публикация и откат

Для публикации используйте production-сборку Next.js или Docker-образ. До окончательной приёмки не удаляйте `cv.html`. Для отката верните веб-серверу прежнюю точку входа `cv.html`; данные и код новой версии при этом остаются в репозитории.
